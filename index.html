Calendar

Синхронізація дат судових засідань із Google Calendar

Calendar — це настільна програма для Windows, якою користуються юристи для обліку своїх судових справ. Програма бере розклад судових засідань із відкритих даних судової влади України (data.gov.ua) і порівнює його з реєстром справ користувача (файл Excel на його комп'ютері).

Для справ, які знайдено в реєстрі, програма створює, оновлює або видаляє події в Google Calendar самого користувача. Так дата, час, суд і номер справи потрапляють у календар автоматично.

Доступ до Google Calendar потрібен лише для роботи з подіями судових засідань. Програма працює локально на комп'ютері користувача, не має власного сервера і нікому не передає дані з облікового запису Google.

About (English)

Calendar is a Windows desktop application for lawyers. It reads public court hearing schedules from Ukrainian open data (data.gov.ua), matches them against the user's own case registry (a local Excel file), and creates, updates or deletes the corresponding hearing events in the user's own Google Calendar.

Google Calendar access is used only to manage these hearing events. The app runs locally on the user's computer, has no server of its own, and does not share Google user data with anyone.
