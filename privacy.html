Політика конфіденційності

Програма «Calendar» · Редакція від 01.11.2026

1. Які дані Google використовуються

  • Програма отримує доступ лише до Google Calendar користувача, і лише після того, як користувач сам надав дозвіл на екрані входу Google.
  • Програма читає, створює, змінює та видаляє тільки події судових засідань, які вона сама створила в календарі, вказаному в її налаштуваннях.
  • Програма не читає контакти, пошту, файли та інші дані облікового запису Google.

2. Де зберігаються дані

  • Ключ доступу (OAuth-токен) зберігається локально на комп'ютері користувача, у папці програми.
  • Реєстр справ і локальна база даних також зберігаються лише на комп'ютері користувача.
  • У програми немає власного сервера. Розробник не отримує і не зберігає жодних даних користувачів.

3. Передача третім особам

  • Дані з облікового запису Google нікому не передаються, не продаються і не використовуються для реклами.
  • Якщо користувач сам увімкнув сповіщення в Telegram, програма надсилає в обраний ним чат перелік засідань. Цей перелік формується з відкритих даних судів і локального реєстру справ, а не з даних облікового запису Google.

4. Відповідність політиці Google

Використання і передача інформації, отриманої через Google API, відповідають вимогам Google API Services User Data Policy, зокрема вимогам щодо обмеженого використання (Limited Use).

5. Як відкликати доступ і видалити дані

  • Відкликати доступ можна будь-коли на сторінці myaccount.google.com/permissions.
  • Щоб видалити збережений токен і локальні дані, достатньо видалити папку програми з комп'ютера.

Privacy Policy (English)

  • Data accessed. With the user's explicit consent, the app accesses only the user's Google Calendar. It reads, creates, updates and deletes only the court hearing events it manages in the calendar selected in its settings. It does not access contacts, email, files or any other Google account data.
  • Storage. The OAuth token, the case registry and the local database are stored only on the user's computer. The app has no server, and the developer does not receive or store any user data.
  • Sharing. Google user data is not shared with, sold to, or used for advertising by anyone. Optional Telegram notifications, which the user enables, are built from public court data and the local registry, not from Google user data.
  • Limited Use. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access. Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app folder removes the stored token and all local data.
